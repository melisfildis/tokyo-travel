Tokyo Travel 🗼

Welcome to the Tokyo Travel project! This repository contains the code for a web project dedicated to Tokyo.

🌐 Live Website

You can view and interact with the live website here: https://melisfildis.github.io/tokyo-travel/


🚀 How to Run Locally

If you want to download and run this project on your own machine:

Clone this repository to your local machine using:

git clone https://github.com/melisfildis/tokyo-travel.git


Navigate to the project folder.

Open the index.html file in your favorite web browser.
